# WGMA 2026 Ticket System — Fixes Applied

## Issues Resolved

### 1. **Ticket Generation Error: "The path argument must be of type string. Received undefined"**
**Root Cause:** The `ticket.js` file had an outdated function signature that didn't match how it was being called from `server.js`.

**What Was Wrong:**
- `ticket.js` expected `buildTicket(order, outputPath)` with 2 parameters
- `server.js` was calling `buildTicket(order, tier, EVENT)` with 3 parameters
- The function was trying to access `order.image` which doesn't exist
- It was trying to write to disk instead of returning a Buffer

**Fixes Applied:**
- Updated `buildTicket()` signature to accept `(order, tier, event)` parameters
- Added proper error handling with validation for tier and art property
- Changed to return a JPEG Buffer instead of writing to disk
- Fixed QR code generation to use `order.reference` instead of `order.orderId`
- Wrapped `getBuffer()` in a Promise since Jimp 0.22 uses callback-based API

### 2. **Missing Artwork Files**
**Root Cause:** The `public/img/` directory didn't exist, and artwork files `ticket-ga.jpg` and `ticket-vip.jpg` were missing.

**Fix Applied:**
- Created `public/img/` directory
- Generated `ticket-ga.jpg` and `ticket-vip.jpg` using ImageMagick
- Both files are valid JPEG images that Jimp can read and composite with QR codes

### 3. **Email Image Delivery (Previously Fixed)**
The Content-ID (cid:) references in email attachments were already correctly implemented in a prior session to fix broken image display in emails.

## How It Works Now

### Flow for Card Payments (HandyPay):
1. Customer selects tier (GA or VIP) and quantity
2. Frontend redirects to HandyPay checkout
3. Customer pays via card
4. HandyPay webhook hits `/webhook/handypay`
5. Server calls `buildTicket(order, tier, EVENT)` → generates 38KB JPEG with QR code
6. Server sends email via SendGrid with ticket as Content-ID attachment
7. Customer receives ticket email with working QR code image

### Flow for Mobile Money (Lynk):
1. Customer selects tier (now works for both GA and VIP!)
2. Server reserves seat, sends Lynk payment instructions
3. Customer pays via Lynk mobile money
4. Admin confirms payment in `/admin.html`
5. Server calls `buildTicket(order, tier, EVENT)` → generates 38KB JPEG with QR code
6. Server sends ticket email via SendGrid
7. Customer receives ticket email

## Technical Details

### Ticket Image Generation:
- **Input:** Artwork JPEG (506x606px) + order reference code
- **Process:** 
  1. Load artwork with Jimp
  2. Generate QR code PNG from order reference
  3. Composite QR code onto artwork (bottom-right corner)
  4. Convert to JPEG at 90% quality
- **Output:** Base64-encoded JPEG buffer (38KB typical)

### Email Attachment Format:
```javascript
{
  filename: `wgma-ticket-${reference}.jpg`,
  content: base64String,
  type: 'image/jpeg',
  encoding: 'base64',
  contentId: `ticket-${reference}`,
  disposition: 'inline'
}
```

### QR Code Details:
- **Data:** Order reference code (e.g., "WGMA2026-ABC123")
- **Format:** PNG (generated by qrcode library)
- **Size:** 200x200px on ticket
- **Error Correction:** High level (can scan with partial damage)
- **Usage:** Scanned at venue entrance for admission
